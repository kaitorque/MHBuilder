      Where is my save file?
      1. In the file window, paste this into the address bar:
        C:\Program Files (x86)\Steam\userdata
      2. Open the numbered folder (your Steam account), then 582010 → remote.
      3. Pick SAVEDATA1000, the file with no extension.

      Steam installed somewhere else? userdata is always in the folder Steam itself is installed in (right-click the Steam shortcut → Open file location), not in a game library folder.
